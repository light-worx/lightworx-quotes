# Obsidian Quotes Plugin

This plugin opens a panel where users can search for quotes from a specified folder within the vault. Clicking on any quote in the search list will add an embed link to the clipboard that can be pasted into the current document. I use this for preparing talks and sermons and I follow a file naming convention that includes the date on which the talk was given. So when quotes are listed, the list will also specify the date and place where the quote was last used.
